## インストール

<Steps>

1. Claude Code のセッションで次を入力します。

   ```text
   /plugin install ide-mod --marketplace jkf87/ide-mod
   ```

2. マーケットプレイスを追加するか聞かれたら `y`、スコープは user を選びます。

3. 新しいセッションを開くと IDE ペインが自動で開きます。今のセッションでは `/ide` で開きます。表示されない場合は `/reload-plugins` を実行してください。

</Steps>

新しいバージョンが出たら、ターミナルでは `/reload-plugins`、デスクトップアプリでは `claude plugin update ide-mod@ide-mod` を実行してから、新しいセッションを開きます。デスクトップアプリはインストール時に作ったコピーを読むので、更新を取り込まないと反映されません。

## 機能

- **エージェントボード**: メインとサブエージェントを、誰が誰を起動したかのツリーで表示します。モデル・effort・担当タスク・現在の作業・経過時間を表示し、人が任せた作業は緑、現在の作業は黄色で色分けします。20 秒ごとに haiku が各エージェントに 1 行の要約を付けます。
- **システム状態**（ボードの最上部）: メモリ使用量とメモリプレッシャー、スワップ、ディスク使用率を 1 行で表示します。プレッシャーが警告・危険のとき、またはスワップやディスクがかなり埋まっているときは、黄色・赤に変わります。`z` を押すと、メモリを多く使っているアプリが 6 つ表示されます。
- **使用上限バンド**（入力欄の上）: Claude の 5 時間・週間・モデル別週間の上限とコンテキスト使用率、Codex の上限、Antigravity の Gemini・Claude/GPT の上限を、提供元ごとに 1 行で表示します。70% を超えると黄色、90% を超えると赤です。`/limits compact` で 1 行表示、`/limits off` で非表示になります。
- **エクスプローラー**: フォルダツリーと最大 8 個のタブ。シンタックスハイライト、Markdown レンダリング、Claude が変更したファイルへの `●` 表示に対応します。
- **HWP・HWPX・PDF ビューアー**: [rhwp](https://github.com/edwardkim/rhwp) と [pdf.js](https://github.com/mozilla/pdf.js) でページを描画します。グラフィックスのないターミナルでも、表の罫線と配置を保った文字グリッドで表示し、kitty・Ghostty 系のターミナルでは実際のページ画像を表示します。
- **リクエスト履歴**（`q`）: このセッションで人が送ったリクエストを全文のまま集めて表示します。バックグラウンド作業の通知や他セッションのメッセージは除きます。セッションを開き直しても残り、`c` ですべてコピーできます。
- **ハンドオフ**（`i`）: ボードにセッション ID が表示されます。`i` を押すと、今開いている他の Claude セッションの一覧と、ハンドオフ文（セッション ID、会話記録のパス、`claude --resume` コマンド、ユーザーが送ったリクエスト）が出ます。セッションを選ぶとそのセッションへ直接送られ、`c` でコピーして Codex など別のエージェントに貼り付けることもできます。`/handoff <セッション名> [メモ]` でも送れます。
- **講義字幕**（`/lecture`）: Claude の作業内容を、やさしい文章で入力欄の上に表示します。
- **文体ゲート**（`/style-gate`）: 韓国語原稿の AI っぽいパターンを数えて、合格・警告・中断を判定します。

## コマンド

| コマンド | 内容 |
|---|---|
| `/ide [パス]` | IDE ペインを開きます |
| `/ide auto on\|off` | 新しいセッションごとにペインを自動で開くか設定します（既定はオン） |
| `/open <パス>` | フォルダやファイルをペインで開きます |
| `/limits [full\|compact\|off\|refresh]` | 使用上限バンドの表示を切り替える、または再取得します |
| `/handoff [セッション名] [メモ]` | ハンドオフ文を表示する、または他のセッションに送ります |
| `/lecture [on\|off]` | 講義字幕 |
| `/style-gate [ファイル\|on\|off]` | 文体ゲート |

## アクセス範囲

[安全チェック](/ja/guide/safety-checklist/)の基準で、この Mod が触れる範囲を書きます。

- **ファイル読み取り**: エクスプローラーと文書ビューアーが、作業フォルダのファイルを読みます。ハンドオフはセッションの会話記録ファイルのパスを探します。
- **プログラム実行**: 文書を描画するために Node.js と画像変換プログラムを、システム行のために `sysctl`・`vm_stat`・`df`・`ps` を、使用上限のために `codex app-server` と `agy` を実行します。Codex と Antigravity は、それぞれのログインで自分のサービスに使用量を問い合わせます。
- **ネットワーク**: Claude の使用上限を 1 分ごとに Anthropic の使用量 API から取得します。セッションの認証情報ハンドルを使うので、トークンは Mod からは見えません。ボードの要約は 20 秒ごとに、エージェントの最近の活動を haiku に送ります（`s` でオフ）。どちらも自分のアカウントの Anthropic API を使います。それ以外にデータを送ることはありません。
- **他のセッション**: ハンドオフは開いているセッションの一覧を読み、選んだセッションにだけメッセージを送ります。2 つのセッションの権限モードが異なる場合は、受け取る側で承認しないと届きません。
- 使用上限とシステム状態は、バンドやペインが画面に出ているときだけ取得します。
