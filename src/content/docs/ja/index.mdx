## Mod でできること

<CardGrid>
  <Card title="ペインとバンドを描画します" icon="laptop">
    会話の横にペイン（pane）、入力欄の上にバンド（band）を表示します。ボタンや入力欄も置けます。
  </Card>
  <Card title="ツール呼び出しを守ります" icon="warning">
    `rm -rf` のような危険なコマンドを止めて確認したりブロックしたりし、シークレットはモデルに見える前に隠します。
  </Card>
  <Card title="使用量を表示します" icon="information">
    コンテキスト、トークン、コスト、5 時間・週間の上限をステータスラインやペインに常時表示します。
  </Card>
  <Card title="コマンドを追加します" icon="puzzle">
    Claude のターンを介さず即実行される `/コマンド` を作れます。Claude が作業中でも動きます。
  </Card>
</CardGrid>
