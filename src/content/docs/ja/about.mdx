**Claude Code Mod Guide** は、Claude Code の Mod（function hooks プラグイン）を使う人・作る人のための、非公式のコミュニティガイドです。6 言語（한국어、English、日本語、简体中文、Français、Deutsch）で同じ内容を提供しています。

## なぜ作ったのか

Mod は強力ですが、まだ early access の段階で、整理された資料が多くありません。インストールは 1 行で済みますが、何に触れるのかを理解したうえで入れる人は多くありません。このサイトは次の 3 つを一か所にまとめています。

- はじめて使う人のための概念とインストール方法
- インストール前に確認する安全基準
- 公開されている Mod を探せるディレクトリ

## データの出典

- Mod ディレクトリは [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods) の `data/mods.json`（CC0）から取得しています。検証を通過し、アーカイブされていない項目だけを掲載し、分類はこのサイトが名前と説明をもとに付けました。
- API の説明は、Claude Code が同梱して配布している型定義を基準にしています。
