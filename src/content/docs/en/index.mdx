## What mods can do

<CardGrid>
  <Card title="Draw panes and bands" icon="laptop">
    Open a pane next to the conversation or a band above the prompt. You can even add buttons and input fields.
  </Card>
  <Card title="Guard tool calls" icon="warning">
    Catch dangerous commands like `rm -rf` to ask or block them, and mask secrets before the model sees them.
  </Card>
  <Card title="Show usage" icon="information">
    Keep context, tokens, cost, and 5-hour and weekly limits visible in the status line or a pane.
  </Card>
  <Card title="Add commands" icon="puzzle">
    Build `/commands` that run right away, without a Claude turn. They work even while Claude is busy.
  </Card>
</CardGrid>
