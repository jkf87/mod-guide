We chose these from the [directory](/en/mods/directory/) by usefulness and access scope. Star counts reflect the repositories at the time this page was written. When one repository holds several mods, the star count applies to all of them.

<Aside type="caution">
A pick is not an endorsement. Go through the [safety check](/en/guide/safety-checklist/) before you install, and be especially careful with access level 2 and above in company repositories.
</Aside>

Access levels: **0** draws and remembers only · **1** reads files · **2** writes and executes · **3** network

## Usage and context

| mod | What it does | Level |
|---|---|---|
| [usage-band](https://github.com/KhadeerBasha1232/claude-usage-mod/tree/main/plugins/usage-band) | Shows the 5-hour and weekly limits and their reset times on one line above the prompt | 2 |
| [quota-meter](https://github.com/Arunjay4213/claude-mods/tree/main/plugins/quota-meter) | Shows your plan limits (5-hour and 7-day windows) | 0 |
| [context-lens](https://github.com/Arunjay4213/claude-mods/tree/main/plugins/context-lens) | Pins a line showing how full the context window is and how much it grows each turn | 0 |
| [token-weather](https://github.com/hamzafer/claude-code-mods/tree/main/mods/token-weather) | Draws a context forecast and a prompt cache expiry countdown | 2 |
| [budget-guard](https://github.com/Arunjay4213/claude-mods/tree/main/plugins/budget-guard) | Stops the session before it goes over a budget you set | 2 |

## Watching agents

| mod | What it does | Level |
|---|---|---|
| [agent-flow](https://github.com/Charlie0113-T/claude-agent-flow) | A pane that shows subagents and teammates as a tree | 0 |
| [agentpane](https://github.com/xuanji86/claude-agentpane) | Lists the subagents a session launched, and what each is doing, in a side pane | 2 |
| [cctop](https://github.com/tomstagl/cctop/tree/main/plugin) | A btop-style dashboard of Claude Code's internal state | 2 |
| [ide-mod](/en/mods/ide-mod/) | An agent board plus a file explorer and document viewer in one pane | 2 |

## Safety

| mod | What it does | Level |
|---|---|---|
| [blast-radius](https://github.com/hamzafer/claude-code-mods/tree/main/mods/blast-radius) | Catches dangerous Bash commands and shows what would change before they run | 2 |
| [secret-redactor](https://github.com/ray-amjad/awesome-claude-code-function-hooks/tree/main/plugins/secret-redactor) | Masks secrets, emails, and IPs in the conversation history | 0 |
| [collision-guard](https://github.com/nateherkai/claude-code-mods/tree/main/collision-guard) | Asks first when Claude is about to edit a file that was changed in another window within the last 30 minutes | 2 |
| [recording-mode](https://github.com/nateherkai/claude-code-mods/tree/main/recording-mode) | Hides keys, personal information, and business numbers with `/rec` before you record your screen | 2 |
