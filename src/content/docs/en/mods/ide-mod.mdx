[ide-mod](https://github.com/jkf87/ide-mod) is a mod published by the author of this guide. The top of the pane holds **system status and the agent board**, and the bottom holds a **file tree and tabbed editor**. Above the prompt, a **Claude, Codex, and Antigravity usage band** appears. The pane opens by itself when you start a new session.

## Install

<Steps>

1. In a Claude Code session, enter:

   ```text
   /plugin install ide-mod --marketplace jkf87/ide-mod
   ```

2. When asked whether to add the marketplace, answer `y` and choose user as the scope.

3. The IDE pane opens by itself in a new session. In the current session, open it with `/ide`. If you don't see it, run `/reload-plugins`.

</Steps>

When a new version comes out, run `/reload-plugins` in the terminal, or `claude plugin update ide-mod@ide-mod` in the desktop app, then open a new session. The desktop app reads the copy it made at install time, so the update only takes effect once it has pulled it.

## What it does

- **Agent board**: Shows the main agent and subagents as a tree of who launched whom. It displays the model, effort, assigned task, current activity, and elapsed time. Tasks a person assigned are green, and current activity is yellow. Every 20 seconds, haiku adds a one-line summary for each agent.
- **System status** (top of the board): Shows memory use and memory pressure, swap, and disk usage on one line. It turns yellow or red when pressure is at warning or critical, or when swap or disk is nearly full. Press `z` to see the 6 apps using the most memory.
- **Usage band** (above the prompt): Shows Claude's 5-hour, weekly, and per-model weekly limits plus context usage, Codex limits, and Antigravity's Gemini and Claude/GPT limits, one line per source. Above 70% it turns yellow, above 90% red. `/limits compact` makes it one line, and `/limits off` hides it.
- **Explorer**: A folder tree and up to 8 tabs. It has syntax highlighting, Markdown rendering, and a `●` mark on files Claude edited.
- **HWP, HWPX, and PDF viewer**: Draws pages with [rhwp](https://github.com/edwardkim/rhwp) and [pdf.js](https://github.com/mozilla/pdf.js). In terminals without graphics, it shows a text grid that keeps table borders and alignment. In kitty and Ghostty-family terminals, it shows actual page images.
- **Request history** (`q`): Collects the requests you sent this session, in full. Background task notifications and messages from other sessions are left out. It stays even after you reopen the session, and `c` copies everything.
- **Handoff** (`i`): The board shows the session ID. Press `i` to see the other Claude sessions that are open, plus a handoff text (session ID, transcript path, the `claude --resume` command, and the requests you sent). Select a session to send it there directly, or press `c` to copy it and paste it into another agent such as Codex. You can also send it with `/handoff <session name> [note]`.
- **Lecture captions** (`/lecture`): Shows what Claude is doing above the prompt in plain sentences.
- **Style gate** (`/style-gate`): Counts AI-sounding patterns in a Korean manuscript and rules pass, warn, or stop.

## Commands

| Command | What it does |
|---|---|
| `/ide [path]` | Opens the IDE pane |
| `/ide auto on\|off` | Sets whether the pane opens by itself in every new session (on by default) |
| `/open <path>` | Opens a folder or file in the pane |
| `/limits [full\|compact\|off\|refresh]` | Changes the look of the usage band or refetches it |
| `/handoff [session name] [note]` | Shows the handoff text or sends it to another session |
| `/lecture [on\|off]` | Lecture captions |
| `/style-gate [file\|on\|off]` | Style gate |

## Access scope

Here is what this mod can reach, following the [safety checklist](/en/guide/safety-checklist/).

- **File reading**: The explorer and document viewers read files in the working folder. Handoff looks up the path of the session transcript file.
- **Running programs**: To draw documents it runs Node.js and an image conversion program; for the system line it runs `sysctl`, `vm_stat`, `df`, and `ps`; for usage limits it runs `codex app-server` and `agy`. Codex and Antigravity ask their own services for usage with their own logins.
- **Network**: Every minute it fetches Claude usage limits from Anthropic's usage API. It uses the session's credential handle, so the mod never sees the token. Every 20 seconds the board summary sends each agent's recent activity to haiku (`s` turns it off). Both use the Anthropic API on your account. It sends no data anywhere else.
- **Other sessions**: Handoff reads the list of open sessions and sends a message only to the session you select. If the two sessions have different permission modes, the receiving side must approve before it is delivered.
- Usage limits and system status are fetched only while the band or pane is on screen.

Function hooks are an early access API. This mod was built and tested on Claude Code 2.1.290 to 2.1.294. Its UI text is in Korean.
