**Claude Code Mod Guide** is an unofficial community guide for people who use and build Claude Code mods (function hooks plugins). It offers the same content in six languages: Korean, English, Japanese, Simplified Chinese, French, and German.

## Why we made it

Mods are powerful, but they are still in early access and well-organized material is scarce. Installing one takes a single line, yet few people know what a mod touches before they install it. This site brings three things together:

- Concepts and installation steps for first-time users
- Safety criteria to check before you install
- A directory where you can browse public mods

## Data sources

- The mod directory comes from `data/mods.json` (CC0) in [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods). It lists only entries that pass validation and are not archived. This site assigned the categories from each mod's name and description.
- API descriptions are based on the type definitions that ship with Claude Code.
