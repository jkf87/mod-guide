Der **Claude Code Mod Guide** ist ein inoffizieller Community-Guide für alle, die Mods (Function-hooks-Plugins) für Claude Code nutzen und bauen. Er bietet denselben Inhalt in sechs Sprachen (한국어, English, 日本語, 简体中文, Français, Deutsch).

## Warum es diese Seite gibt

Mods sind mächtig, aber noch im Early Access, und es gibt wenig aufbereitetes Material. Die Installation ist eine einzige Zeile, doch kaum jemand weiß vor der Installation, worauf eine Mod zugreift. Diese Seite bündelt drei Dinge an einem Ort:

- Konzepte und Installation für den Einstieg
- Sicherheitskriterien, die du vor der Installation prüfst
- Ein Verzeichnis, in dem du öffentliche Mods durchsuchen kannst

## Datenquellen

- Das Mod-Verzeichnis stammt aus `data/mods.json` (CC0) von [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods). Aufgenommen werden nur Einträge, die die Validierung bestehen und nicht archiviert sind. Die Kategorien hat diese Seite anhand von Name und Beschreibung vergeben.
- Die API-Beschreibungen basieren auf den Typdefinitionen, die Claude Code mitliefert.

## Wer dahintersteckt
