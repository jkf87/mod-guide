**Claude Code Mod Guide** est un guide communautaire non officiel pour celles et ceux qui utilisent et créent des mods (plugins à function hooks) pour Claude Code. Le même contenu est proposé en 6 langues (한국어, English, 日本語, 简体中文, Français, Deutsch).

## Pourquoi ce site

Les mods sont puissants, mais encore en accès anticipé (early access), et la documentation organisée manque. L'installation tient en une ligne, mais peu de gens savent à quoi un mod accède avant de l'installer. Ce site réunit trois choses au même endroit.

- Les concepts et la marche à suivre pour l'installation, pour les débutants
- Les critères de sécurité à vérifier avant d'installer
- Un répertoire pour explorer les mods publics

## Sources des données

- Le répertoire des mods provient du fichier `data/mods.json` (CC0) de [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods). Seules les entrées validées et non archivées sont publiées, et la classification a été établie par ce site d'après le nom et la description.
- Les explications sur l'API s'appuient sur les définitions de types livrées avec Claude Code.
