Référence : scan du catalogue communautaire du 2026-10-04, Claude Code 2.1.289

Les chiffres de cet article viennent d'un nouveau comptage, en Python, du fichier `data/mods.json` (CC0) du catalogue [awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods). Le catalogue cherche des mods sur GitHub, exécute `claude plugin validate` sur chaque dépôt, puis en extrait les hooks et les appels `$` à partir de la sortie. Le fichier a été généré le 2026-10-04 à 08:26 (UTC). Les mods apparus après cette heure n'y figurent pas.

## Ce que nous avons compté

Le catalogue contient 1 919 entrées trouvées dans 1 171 dépôts. Toutes ne sont pas des mods à installer.

| Type | Entrées | Signification |
| --- | ---: | --- |
| `mod` | 1 752 | Mod ordinaire |
| `fixture` | 93 | Exemple de test dans un dossier comme `tests/` ou `examples/` |
| `catalog` | 39 | Entrée d'un dépôt qui regroupe les mods d'autres personnes |
| `duplicate` | 28 | Même mod qu'une autre entrée |
| `builtin` | 4 | Mods intégrés du dépôt `anthropics/claude-code` |
| `mirror` | 3 | Copies de mods intégrés |

Le [répertoire des mods](/fr/mods/directory/) de ce site ne retient, parmi les `mod` et `builtin`, que ceux qui ne sont pas archivés, ne sont pas des doublons et passent la validation sans avertissement. Il reste ainsi **1 488 mods, 777 dépôts et 690 auteurs**. Sauf mention contraire, les chiffres ci-dessous portent sur ces 1 488 mods.

## Un afflux en trois jours

Le champ `createdAt` du catalogue est l'heure de création du dépôt. Elle ne coïncide pas toujours avec le jour où le mod a été publié : les 102 dépôts créés avant septembre 2026, par exemple, ont reçu leurs mods plus tard.

| --- | ---: | ---: |
| Avant septembre 2026 | 102 | 154 |
| Septembre 2026 | 108 | 190 |
| 1er octobre | 36 | 52 |
| 2 octobre | 258 | 453 |
| 3 octobre | 228 | 568 |
| 4 octobre (jusqu'à 08:26) | 42 | 68 |
| 5 octobre | 3 | 3 |

Les 2 et 3 octobre, 486 dépôts ont été créés, soit 63 % des 777. Le chiffre du 3 octobre inclut les 117 mods d'un seul dépôt créé ce jour-là, [mako-code/gobworks](https://github.com/mako-code/gobworks). [KilimcininKorOglu/claude-code-mods](https://github.com/KilimcininKorOglu/claude-code-mods), créé le 18 septembre, a lui aussi ajouté 53 mods en une journée.

Claude Code 2.1.287 est apparu sur le registre npm le 2026-10-01 à 16:59 (UTC). C'est la version où les function hooks sont activés par défaut, comme l'indique la [FAQ](/fr/faq/). Parmi les 36 dépôts créés le 1er octobre, 29 l'ont été après 17 h. Depuis cette heure, 560 dépôts sur 777 (72 %) ont été créés, et ils contiennent 1 137 mods sur 1 488 (76 %). Les dates coïncident, mais le catalogue n'indique pas pourquoi un dépôt a été créé : nous ne pouvons donc pas parler de cause.

## Un dépôt sur cinq n'a pas de licence

Le catalogue enregistre la licence reconnue par GitHub (identifiant SPDX).

| Licence | Dépôts | Part |
| --- | ---: | ---: |
| MIT | 555 | 71,4 % |
| Aucune | 164 | 21,1 % |
| Apache-2.0 | 25 | 3,2 % |
| NOASSERTION | 24 | 3,1 % |
| AGPL-3.0 | 3 | 0,4 % |
| GPL-3.0 · Unlicense | 2 chacune | 0,3 % |
| GPL-2.0 · MIT-0 | 1 chacune | 0,1 % |

Par mod, 324 mods (21,8 %) n'ont pas de licence. Un dépôt sans fichier de licence relève du droit d'auteur par défaut : sans autorisation de l'auteur, personne n'a le droit de copier le code, de le modifier ni de le redistribuer. Les conditions d'utilisation de GitHub permettent de consulter et de forker un dépôt public. En revanche, vous ne devez pas copier ce code dans votre propre mod ni diffuser une version modifiée. Si nécessaire, demandez à l'auteur d'ajouter une licence en ouvrant une issue. `NOASSERTION` signifie qu'il existe un fichier de licence que GitHub n'a pas pu identifier : ouvrez ce fichier vous-même pour vérifier.

## Comment s'en servir pour choisir

- Le nombre d'étoiles est celui du nom du dépôt. Pour choisir un mod, regardez le dernier commit du dossier de ce mod et son code source.
- Pour un mod issu d'un grand dépôt de collection, vérifiez s'il dépend d'autres mods du même dépôt.
- Un mod sans licence peut être installé et essayé, mais vous ne devez pas en reprendre le code.
- Pour l'étendue des accès, voir [Ce que les mods touchent réellement](/fr/articles/what-mods-touch/) ; pour les causes d'échec de validation, voir [Les mods qui échouent à la validation](/fr/articles/validation-failures/).
