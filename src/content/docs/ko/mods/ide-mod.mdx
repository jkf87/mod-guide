[ide-mod](https://github.com/jkf87/ide-mod)는 이 가이드를 만든 사람이 공개한 mod예요. 창 위쪽에는 **시스템 상태와 에이전트 보드**가, 아래쪽에는 **파일 트리와 탭 에디터**가 있어요. 입력창 위에는 **Claude·Codex·Antigravity 사용 한도**가 떠요. 새 세션을 열면 창이 저절로 열려요.

## 설치

<Steps>

1. Claude Code 세션에서 입력해요.

   ```text
   /plugin install ide-mod --marketplace jkf87/ide-mod
   ```

2. 마켓플레이스를 추가할지 물으면 `y`, 범위는 user를 골라요.

3. 새 세션을 열면 IDE 창이 저절로 열려요. 지금 세션에서는 `/ide`로 열어요. 보이지 않으면 `/reload-plugins`를 실행해요.

</Steps>

새 버전이 나오면 터미널에서는 `/reload-plugins`, 데스크톱 앱에서는 `claude plugin update ide-mod@ide-mod`를 실행한 뒤 새 세션을 열어요. 데스크톱 앱은 설치할 때 만든 사본을 읽어서 업데이트를 받아야 바뀌어요.

## 무엇을 하나

- **에이전트 보드**: 메인과 서브에이전트를 누가 누구를 띄웠는지 트리로 보여줘요. 모델·effort·맡은 작업·지금 하는 일·경과 시간을 띄우고, 사람이 맡긴 일은 초록, 지금 하는 일은 노랑으로 칠해요. 20초마다 haiku가 에이전트마다 한 줄 요약을 붙여요.
- **시스템 상태**(보드 맨 위): 메모리 사용량과 메모리 압력, 스왑, 디스크 사용률을 한 줄로 보여줘요. 압력이 경고·위험이거나 스왑·디스크가 많이 차면 노랑·빨강으로 바뀌어요. `z`를 누르면 메모리를 많이 쓰는 앱 6개가 나와요.
- **사용 한도 띠**(입력창 위): Claude 5시간·주간·모델별 주간 한도와 컨텍스트 사용률, Codex 한도, Antigravity의 Gemini·Claude/GPT 한도를 출처마다 한 줄로 보여줘요. 70%를 넘으면 노랑, 90%를 넘으면 빨강이에요. `/limits compact`로 한 줄, `/limits off`로 숨겨요.
- **탐색기**: 폴더 트리와 최대 8개 탭. 문법 하이라이트, 마크다운 렌더, Claude가 고친 파일 `●` 표시.
- **HWP·HWPX·PDF 뷰어**: [rhwp](https://github.com/edwardkim/rhwp)와 [pdf.js](https://github.com/mozilla/pdf.js)로 쪽을 그려요. 그래픽이 없는 터미널에서도 표 테두리와 정렬을 살린 글자 격자로 보여주고, kitty·Ghostty 계열 터미널에서는 실제 쪽 그림을 띄워요.
- **요청 기록**(`q`): 이번 세션에서 사람이 보낸 요청을 전문 그대로 모아 보여줘요. 백그라운드 작업 알림이나 다른 세션의 메시지는 빼요. 세션을 다시 열어도 남고, `c`로 전부 복사해요.
- **핸드오프**(`i`): 보드에 세션 ID가 떠요. `i`를 누르면 지금 열려 있는 다른 Claude 세션 목록과 핸드오프 글(세션 ID, 대화 기록 경로, `claude --resume` 명령, 사용자가 보낸 요청)이 나와요. 세션을 누르면 그 세션에 바로 보내고, `c`로 복사해 Codex 같은 다른 에이전트에 붙여 넣을 수도 있어요. `/handoff <세션 이름> [메모]`로도 보내요.
- **강의 자막**(`/lecture`): Claude가 하는 일을 입력창 위에 쉬운 문장으로 보여줘요.
- **문체 게이트**(`/style-gate`): 한국어 원고의 AI티 패턴을 세서 통과·경고·중단을 판정해요.

## 명령

| 명령 | 하는 일 |
|---|---|
| `/ide [경로]` | IDE 창을 열어요 |
| `/ide auto on\|off` | 새 세션마다 창을 저절로 열지 정해요 (기본 켜짐) |
| `/open <경로>` | 폴더나 파일을 창에 열어요 |
| `/limits [full\|compact\|off\|refresh]` | 사용 한도 띠 모양을 바꾸거나 다시 받아요 |
| `/handoff [세션 이름] [메모]` | 핸드오프 글을 보여 주거나 다른 세션에 보내요 |
| `/lecture [on\|off]` | 강의 자막 |
| `/style-gate [파일\|on\|off]` | 문체 게이트 |

## 접근 범위

[안전 점검](/ko/guide/safety-checklist/) 기준으로 이 mod가 닿는 곳을 적어요.

- **파일 읽기**: 탐색기와 문서 뷰어가 작업 폴더의 파일을 읽어요. 핸드오프는 세션 대화 기록 파일의 경로를 찾아요.
- **프로그램 실행**: 문서를 그리려고 Node.js와 이미지 변환 프로그램을, 시스템 줄을 위해 `sysctl`·`vm_stat`·`df`·`ps`를, 사용 한도를 위해 `codex app-server`와 `agy`를 실행해요. Codex와 Antigravity는 각자의 로그인으로 자기 서비스에 사용량을 물어요.
- **네트워크**: Claude 사용 한도를 1분마다 Anthropic 사용량 API에서 받아요. 세션의 자격 증명 핸들을 써서 토큰은 mod에 보이지 않아요. 보드 요약은 20초마다 에이전트의 최근 활동을 haiku에 보내요(`s`로 끄기). 둘 다 내 계정의 Anthropic API를 써요. 그 밖의 곳으로는 데이터를 보내지 않아요.
- **다른 세션**: 핸드오프는 열려 있는 세션 목록을 읽고, 누른 세션에만 메시지를 보내요. 두 세션의 권한 모드가 다르면 받는 쪽에서 승인해야 전달돼요.
- 사용 한도와 시스템 상태는 띠나 창이 화면에 있을 때만 받아요.
