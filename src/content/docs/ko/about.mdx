**Claude Code Mod Guide**는 Claude Code의 mod(function hooks 플러그인)를 쓰고 만드는 사람을 위한 비공식 커뮤니티 가이드예요. 6개 언어(한국어, English, 日本語, 简体中文, Français, Deutsch)로 같은 내용을 제공해요.

## 왜 만들었나

mod는 강력하지만 아직 early access라서 정리된 자료가 적어요. 설치는 한 줄이지만, 무엇에 닿는지 알고 설치하는 사람은 드물어요. 이 사이트는 세 가지를 한곳에 모아요.

- 처음 쓰는 사람을 위한 개념과 설치 방법
- 설치 전에 확인할 안전 기준
- 공개된 mod를 찾아볼 수 있는 디렉터리

## 데이터 출처

- mod 디렉터리는 [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods)의 `data/mods.json`(CC0)에서 가져와요. 검증을 통과하고 보관되지 않은 항목만 싣고, 분류는 이 사이트가 이름과 설명으로 매겼어요.
- API 설명은 Claude Code가 함께 배포하는 타입 정의를 기준으로 해요.

## 만든 사람

[jkf87](https://github.com/jkf87)이 만들고 관리해요. [ide-mod](/ko/mods/ide-mod/)를 만들었어요.

## 고지

이 사이트는 Anthropic이 만들거나 후원하거나 보증하지 않아요. Claude와 Claude Code는 Anthropic의 상표예요. 사이트 운영비를 위해 광고가 실려요. 광고는 추천 내용에 영향을 주지 않아요.

사이트 소스는 [GitHub](https://github.com/jkf87/mod-guide)에 있어요.
