## Mod 能做什么

<CardGrid>
  <Card title="绘制窗口和横条" icon="laptop">
    在对话旁边弹出窗口（pane），在输入框上方显示横条（band），还能放进按钮和输入框。
  </Card>
  <Card title="守住工具调用" icon="warning">
    拦下 `rm -rf` 这类危险命令，询问或直接阻止；密钥在模型看到之前就被遮住。
  </Card>
  <Card title="展示用量" icon="information">
    上下文、Token、费用、5 小时和每周额度，常驻显示在状态栏或窗口里。
  </Card>
  <Card title="添加命令" icon="puzzle">
    制作无需经过 Claude 回合、立即执行的 `/命令`。Claude 工作期间也能运行。
  </Card>
</CardGrid>
