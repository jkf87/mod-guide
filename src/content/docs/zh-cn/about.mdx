**Claude Code Mod Guide** 是写给 Claude Code Mod（函数钩子 (function hooks) 插件）使用者和制作者的非官方社区指南，提供 6 种语言（한국어、English、日本語、简体中文、Français、Deutsch）的相同内容。

## 为什么制作

Mod 功能强大，但仍处于 early access 阶段，整理好的资料很少。安装只要一行命令，却很少有人在清楚 Mod 会触及什么之后才安装。本站把三件事集中在一处。

- 面向初次使用者的概念和安装方法
- 安装前要确认的安全标准
- 可供查找公开 Mod 的目录

## 数据来源

- Mod 目录取自 [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods) 的 `data/mods.json`（CC0）。只收录通过验证且未归档的条目，分类由本站根据名称和描述划分。
- API 说明以 Claude Code 随附发布的类型定义为准。
